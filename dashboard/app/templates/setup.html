Create the schema, then load some data:

cd core
python main.py init
python main.py seed

Or point the dashboard somewhere else — it reads HONEYPOT_DB_PATH, the same variable the collector and the alert engine use: 

set HONEYPOT_DB_PATH=C:\path\to\honeypot_aggregator.db
python main.py

To generate a realistic dataset without running the sensors, use the demo seeder — it writes to its own database file and never touches the shared one: 

cd dashboard
python tools/seed_demo.py

This page is served whenever the read-only handle cannot be opened. It is not an error state in the pipeline — the collector, enricher and alert engine are unaffected by it.
