On spool depth

A node's spool — its pending_events.jsonl backlog — lives on the node and is not part of the Baseline v1.3 event contract, so the central database cannot report it directly and this dashboard does not invent a number for it.

Ingest lag above is what a draining spool looks like from the collector's side: it is measured, not estimated, as received_at − timestamp for every event the node shipped. A node that went offline and came back shows a large worst-case lag and a normal mean; a node that is persistently behind shows both climbing.
